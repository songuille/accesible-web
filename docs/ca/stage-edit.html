Stage Edit (macOS)

Editor de dues pistes dual-mono per a Mac: gravar, editar ones i exportar sense un DAW complet.

Stage Edit és un editor de dues pistes dual-mono per a Mac: gravar, editar ones i exportar sense la complexitat d’un DAW complet.

Característiques

  • Dues pistes dual-mono: ideal per a escena, assaig i podcast.
  • Captura HAL (AUHAL) estable per a preses llargues.
  • Edició d’ona: zoom, selecció, tallar/copiar/enganxar, fades, guany i normalitzar.
  • EQ, compressor i reducció de soroll offline; inserts Audio Unit per pista.
  • Importa àudio i exporta WAV o AIFF; projectes .stageedit amb autosave.

Properament

Aviat al Mac App Store. Mentrestant pots seguir les novetats de Stage Apps.
