Zer egiten du

M32 Patch-ek M32 / X32 Easy Routing (macOS) fluxu azkarra poltsikoraino ekartzen du. Sarrerak eta irteerak segundo gutxitan mapatu: ukitu gelaxka bat esleitzeko, berriro OFF jartzeko, eta kudeatu Local, AES50, AUX eta USB Card OSC bidez kontsolaren sare berean.

App Store promo laburra

Easy Routing-en iOS laguna: M32/X32 routing bisuala iPhone eta iPad-en — ukitu esleitzeko edo OFF, Local / AES50 / AUX / USB.

Ezaugarri nagusiak

  • Sarrera eta irteeretarako matrize routing bisuala iPhone eta iPad-en.
  • Fluxu azkarra: ukitu esleitzeko / berriro OFF.
  • Local, AES50, AUX eta USB/Card bideak.
  • Sare aurkikuntza eta OSC konexio zuzena mesara.
  • Zuzeneko showetarako, stageboxetarako eta oholtzako patch aldaketetarako.
  • Easy Routing Mac-eko osagarria lan-eremu handiagoa behar denean.

Erabili M32 Patch oholtzan telefono edo tabletarekin, eta mantendu Easy Routing Mac-ean edizio sakonagoetarako.
