Stage Recorder (macOS)

Grabadora multipista sencilla para Mac: captura sesiones (p. ej. M32/DN32) y exporta pistas o un WAV estéreo de referencia.

Stage Recorder no pretende ser un DAW: es una grabadora multipista sencilla para Mac. Sirve para obtener las pistas que luego editarás en tu DAW, o un WAV estéreo L/R de referencia.

Características

  • Grabación multipista sencilla: crea una sesión, asigna entradas y graba.
  • Pensada para cabina: captura salidas de mesas como M32 / DN32 hacia el Mac.
  • Exporta las pistas individuales para abrirlas en tu DAW.
  • Exporta también una mezcla estéreo WAV de referencia (L/R).
  • No es un DAW: sin mezcla compleja ni edición avanzada; solo capturar y sacar.
